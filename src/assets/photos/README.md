# Photography slots

The redesigned UI loads real photos from this folder (`<name>.jpg`). Until a
file exists the app shows a soft sand placeholder, so nothing breaks.

Brief: natural, warm, un-staged photos of people in their 60s and 70s doing
everyday healthy things. Bright daylight, no gym intimidation, no stock-pose
smiles. Landscape, about 1200×700, under ~200 KB each.

| File | Used on | Scene |
| --- | --- | --- |
| `home-walk.jpg` | Home hero | An older couple walking in a park |
| `weight.jpg` | Measure Weight | Older woman stepping onto a bathroom scale at home |
| `steps.jpg` | Log Steps | Older man walking a neighbourhood path |
| `water.jpg` | Drink Water | Older woman filling a glass at the kitchen sink |
| `bp.jpg` | Measure Blood Pressure | Older man checking his blood pressure at the table |
| `exercise.jpg` | Exercise tab header | Gentle stretching in a living room |
| `welcome.jpg` | Welcome screen | A smiling older adult with a care-team video call |
